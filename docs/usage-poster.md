# AStock 盘中盯盘使用海报

> Windows 桌面版｜分时价格 + 成交量 + MACD｜信号只提醒，不自动交易

---

## 一条命令启动

```powershell
python -m pip install pystray pillow pandas
pythonw .\tools\intraday_macd_alert.py 002837 --bar
```

把 `002837` 换成任意 6 位 A 股代码。任务栏行情条支持直接修改代码，输入后按回车换股。

需要更完整的图表时使用：

```powershell
pythonw .\tools\intraday_macd_alert.py 002837 --gui
```

停止程序：关闭窗口，或在命令行模式按 `Ctrl+C`。

---

## 三张图看什么

| 图表 | 它回答的问题 | 重点看法 |
| --- | --- | --- |
| Price | 价格往哪边走？ | 价格线、`EMA20`、`VWAP` 的相对位置 |
| Volume / `V` | 这一分钟活跃吗？ | 柱子越高，成交越集中；`V 24.9w` = 最新分钟成交 24.9 万股 |
| MACD | 这段走势还有动能吗？ | 柱子变长表示动能增强，变短表示动能减弱；`DIF/DEA` 看交叉 |

### 快速配合

```text
价格上涨 + 量放大 + MACD 柱变长  -> 走势确认度较好
价格上涨 + 量缩小 + MACD 柱变短  -> 上涨可能乏力
价格下跌 + 量放大               -> 抛压需要警惕
价格创新高但量没有同步放大       -> 注意量价背离
```

量能颜色只表示该分钟价格涨跌，不表示买卖方向；量能必须和价格、MACD 一起判断。

## 任务栏行情条

从左到右：

```text
[代码 / 价格] [Price] [MACD] [V 成交量] [买卖五档] [关闭]
```

- `V 24.9w`：最新已完成分钟成交量，单位为万股。
- 量能柱：每根柱对应一个分钟，柱高代表成交量大小。
- 红色和绿色柱：沿用 A 股习惯，分别表示该分钟上涨和下跌。
- 右键：测试提醒、切换候选公式、打开详细五档和历史日内回测。

任务栏版本为紧凑视图，想看完整价格参考线和量能面板时使用 `--gui`。

---

## MACD 提醒怎么理解

- 金叉/红柱：偏多观察信号，不等于必须买入。
- 死叉/绿柱：偏空观察信号，不等于必须卖出。
- 默认候选逻辑还会参考 `VWAP`、`EMA20`、大盘和板块动量。
- 所有提醒只服务于观察和复盘，程序不会自动下单。

## 常用命令

```powershell
# 主窗口
pythonw .\tools\intraday_macd_alert.py 600519 --gui

# 任务栏行情条
pythonw .\tools\intraday_macd_alert.py 600519 --bar

# 命令行监控
python .\tools\intraday_macd_alert.py 600519 --no-popup

# 项目自检
python -m astock_hub doctor

# 单元测试
python -m pytest tests -q
```

## 数据与边界

- 当前图表面向 Windows 桌面环境。
- 只使用已经结束的分钟行情，避免把未完成分钟误当成完整信号。
- 行情源异常、停牌、非交易时段可能导致暂无数据。
- 本项目仅供个人研究、观察和回测，不构成投资建议。
