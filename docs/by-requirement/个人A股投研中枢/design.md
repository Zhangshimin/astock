# 设计方案

## 架构原则

- 上游项目保持独立 Git 仓库，不做源码合并。
- 统一层通过 Python API、文件适配器、子进程或本地服务调用能力。
- 大型项目使用独立虚拟环境，避免依赖冲突。
- 原始数据、标准化数据和报告分层保存。
- 实盘执行必须单独显式启用，默认不可用。

## 能力链路

```text
AKShare / adata / easy_tdx
              |
雪球 / 东方财富评论 -> 标准化 -> 去重 -> 情绪评分
              |                       |
              +---------- 因子汇总 ---+
                                      |
                             UZI / TradingAgents
                                      |
                         选股 -> 回测 -> 持仓监控
```

## 数据契约

论坛数据统一为以下字段：

- `text`：评论或帖子正文。
- `title`：帖子标题。
- `source`：`xueqiu`、`eastmoney` 或其他来源。
- `created_at`：原始发布时间。
- `likes`、`replies`：互动权重。
- `author`、`url`：溯源信息。
