# 悄盯一股 · Windows x64 独立版

安装插件后输入 `悄盯一股`、`astock`、`stock` 或六位股票代码即可打开工作台。
无需 Python、项目源码、Git、Node.js 或上游仓库。首次启动会自动准备随插件附带的运行组件，不联网下载依赖。

用户配置、启动日志、交易记录与运行组件缓存在 `%LOCALAPPDATA%\QiaodingYigu`。
行情需要联网访问东方财富、腾讯等数据源。语音使用 Windows 自带语音能力。
仅支持 Windows x64；不支持 macOS/Linux。股市数据源可用性不属于离线安装保障范围。

## 开发者打包与发布

此目录已经包含完整的独立运行组件。在 uTools 开发者工具中导入这里的 `plugin.json`，
运行验收后使用开发者工具打包为 `.upx` 并发布。不要只上传 `plugin.json` 或前端文件。
随附 ZIP 是完整分发目录的压缩备份，不能直接改后缀当作 `.upx` 安装。

首次准备组件支持从插件归档释放到用户目录，运行时不向插件安装目录写入数据。
仅分发此目录；不要打包源项目的 `repos/`、`var/`、登录状态或个人交易记录。

从旧版升级后重启旧行情条一次。原有 uTools 设置会继续使用；不再使用旧设置里的 Python 和项目路径。
若旧 uTools 配置保留项目路径，会自动复制旧交易记录到用户目录，不覆盖已有记录。
没有旧配置时，可手动复制 `var/intraday_trades.json` 到用户目录同名文件；已有记录请先备份再合并。
