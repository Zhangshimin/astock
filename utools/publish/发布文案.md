# 悄盯一股

## 一句话简介

专注一只股票，悄悄融入任务栏。变色龙底色随背景适配，支持拖拽、分时行情、MACD、五档盘口与可选声音提醒，小巧低调，随时看一眼。

## 应用介绍

想关注一只股票，又不想让行情窗口占满桌面？悄盯一股把你关心的行情收进任务栏，小巧低调，工作间隙看一眼即可。

- **专注一股，轻巧盯盘**：输入股票代码，打开独立行情条或分时图表；退出 uTools 插件面板后，行情窗口仍可继续运行。
- **融入任务栏，减少打扰**：默认显示在任务栏内部，自动计算挂靠位置。变色龙模式根据周围背景主色调整底色，让窗口更自然地融入桌面。
- **位置随手调整**：支持拖拽并记住位置，双击图表即可恢复自动挂靠。
- **关键信息，一眼掌握**：支持分时价格、成交量、MACD 与五档盘口，按需查看行情和信号。
- **提醒由你决定**：可独立开关声音，选择提示音或语音，设置买卖方向、观察信号、价量条件、提醒时段和发声间隔；关闭声音仍可保留视觉提醒。
- **安装即可使用**：内置运行组件，无需安装 Python、下载源码或选择项目目录。常用设置集中展示，更多选项按需展开。

使用方法：在 uTools 输入「悄盯一股」「astock」「stock」或六位股票代码打开工作台；输入「盯盘 000001」打开行情条，「图表 000001」打开图表，「股票设置」调整偏好。

适用于 Windows x64。行情查询需要网络，数据更新受行情源与网络状态影响。仅供研究与观察，不自动下单，不构成投资建议。

## v0.3.0 版本说明

- 升级为独立 uTools 插件，内置运行组件，安装后无需配置 Python 或源码目录。
- 优化窗口启动与显示检测，默认全天显示，显示时段与提醒时段可分别设置。
- 行情条默认挂靠任务栏内部，自动计算位置，支持拖拽、位置记忆和双击恢复挂靠。
- 新增变色龙底色，按周围背景主色调整窗口底色及文字对比度。
- 简化设置页，常用选项集中展示，声音提醒与高级选项折叠收纳。
- 完善声音提醒：支持独立开关、提示音或语音、信号条件筛选、提醒时段与冷却间隔。
- 支持分时行情、成交量、MACD 与五档盘口；保存设置后自动应用到运行中的新版窗口。
- 精简搜索指令，每个功能不超过 5 个，保留 astock、stock 和股票代码入口。
